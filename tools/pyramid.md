# Pyramid 技术知识库

Pyramid 与本网站统一在 Notes 中维护，覆盖 Linux 内核、C++、eBPF、网络、安全、算法和系统编程。网站中的技术笔记与知识库中的概念页、来源摘要可以配合阅读。

## 阅读入口

- [知识库首页](https://github.com/Sphinxes0o0/notes/blob/main/wiki/pyramid/wiki/home.md)：按主题浏览概念与索引。
- [概念目录](https://github.com/Sphinxes0o0/notes/tree/main/wiki/pyramid/wiki/entities)：查阅技术概念和交叉引用。
- [来源摘要](https://github.com/Sphinxes0o0/notes/tree/main/wiki/pyramid/wiki/sources)：查阅书籍、论文、技术笔记及仓库摘要。
- [综合分析](https://github.com/Sphinxes0o0/notes/tree/main/wiki/pyramid/wiki/synthesis)：阅读跨来源的比较和分析。

## 使用 Obsidian

将仓库中的 `wiki/pyramid/wiki/` 作为 Vault 打开。原有双向链接、主题索引和附件目录保持不变；GitHub 页面会显示双向链接原始文本，在 Obsidian 中可按知识图谱浏览。

后续知识库内容直接在 Notes 中维护。原始资料快照保留在 `wiki/pyramid/raw/`，现有技术笔记仍在 `kernel/`、`ccpp/`、`network/` 等主题目录中编辑。
